# 開車趣・公開版

給 Android 車機（Ottocast P3 等 Android 12 以上的盒子）用的極簡主畫面，免費使用。一創系統製作。

## ⬇️ 下載

**[1tron.ai/carhome.apk](https://1tron.ai/carhome.apk)**（車機瀏覽器直接輸入這個網址）　·　[所有版本與更新說明](https://github.com/pct/carhome-public/releases)

裝好之後，新版會在畫面上方出現「有新版」，點一下就能更新。

## 有什麼
- **地圖最大**：一按就開 Google 地圖；長按可換成別的導航 App。
- **測速照相提醒**：背景常駐，看 YouTube、開地圖時也會唸；系統語音，可選**女聲／男聲**。
- **區間測速**：即時平均時速、還剩多遠、後面最多能開多快。
- **國道路況**：前方事故、施工、塞車用語音提醒。
- **雪隧猜一猜**：按一下就查即時車流，告訴你雪山隧道往宜蘭、往台北各是內線還是外線快。
- **語音控制**：導航、放 YouTube、報時、問前面有沒有測速；也能直接打開 ChatGPT。

## 安裝
1. 在車機瀏覽器輸入 `1tron.ai/carhome.apk`，或把 APK 用隨身碟複製進盒子，在「檔案管理」點它。
2. 跳出「不允許安裝這個來源的應用程式」→「設定」→ 打開「允許這個來源」→ 返回按「安裝」。
3. 開一次「開車趣」，權限都允許（位置、通知；麥克風第一次語音控制時才會問）。
4. 按 Home 鍵選「開車趣」→「一律」，就是預設主畫面。改回原廠：設定 → 應用程式 → 預設應用程式 → 主畫面應用程式。

語音沒有中文：設定 → 提醒語音 →「語音引擎設定」，安裝「Google 語音服務」並下載中文（台灣）。
